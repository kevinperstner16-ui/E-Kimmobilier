# Database

Ce dossier contient tout ce qui concerne la vraie base de données.

Pour Supabase :

1. Crée un projet sur Supabase.
2. Va dans `SQL Editor`.
3. Colle le contenu de `database/supabase/schema.sql`.
4. Lance le script.
5. Copie l’URL du projet et la clé publique dans `.env.local`.

Le site continue de fonctionner sans Supabase grâce au mode localStorage.
